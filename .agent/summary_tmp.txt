【执行模型（最终形态）】
vm.py（极简，零错误处理）：
    import block
    from block import run_next, run_block, reset
    block.run_block()
    while True:
        exec(block.imp)
- block.run_block()：下钻到第一个命中插件的 token，设置全局 imp（插件源码，payload 已拼进源码开头："payload = <repr>\n"+src）
- exec(block.imp) 单参数（用 __main__ 作用域；run_next/run_block/reset 靠 vm.py import 进当前作用域）
- 迭代不递归：run_next 纯推进（_cur_i+=1 + _set_imp 更新 imp）；reset 重跑（_cur_i=0 + _set_imp）；run_block 回调下钻（压栈 _retstack + 切块 + _set_imp）
- _retstack=None 哨兵：None=未启动（入口，初始化+flush+清栈）；[]=已启动（插件下钻回调压栈）；返回栈元素 = (key, i) 对（不存 token 快照）
- 关键：runblock 不预读取——无 _cur_toks 缓存；find_plugin 每次迭代动态 _load_toks(_cur_key)（内存改动立即响应）；_load_toks 优先读 vmstate.cur（editor 实时维护的 [(name,payload)]），内存没有才 fetch(server) 兜底解析（list(iter_tokens(blk)) 仅兜底，引导空 key 取 next_key 第一条 name）；弹栈恢复 (key,i) 后继续动态读
- SystemExit 直接冒泡（零错误处理，不捕获不 flush）
- vmstate.cur_key：当前块 key（editor/rerun 定位用，替代 inspect）

【editor 插件（devdest 模式）】
- 首次 exec（vmstate.ed_init 未设）：创建窗口+事件+状态（key_=vmstate.cur_key, toks=fetch, vmstate.cur[key_]=toks）；重跑复用窗口
- 每次 exec 渲染一帧（dispatch_events + on_draw + flip + sleep(0.016)）后 run_next()；关闭窗口抛 SystemExit
- 窗口常驻（rerun reset 循环回 editor 每帧渲染）；节点头布局（主/子视图顶部块名，row_y 统一行计算）
- 交互：右键主视图 token=拖出；右键子视图=关闭；左键子视图空白=拖动（增量位移）；空格=space_insert（无匹配也插入输入文本）；SHIFT 划选复制/INSERT 粘贴/DELETE 划删；cands=collect(空key递归)+PLUGIN_NAMES(18插件)
